# 🏥 프로덕션 서버 헬스 체크 스킬

향린교회 프로덕션 서버(www.hyanglin.org)의 서비스 가용성과 인프라 상태를 체계적으로 검증한다.

## 📌 트리거 조건

- 사용자가 "헬스 체크", "서버 상태 확인", "health check" 등을 요청했을 때
- 서버 장애 조치 후 복구 확인이 필요할 때
- 정기 점검 시 (수동 또는 `/schedule` 명령)

---

## 🛠️ 실행 방법

### 자동 검증 (5개 항목)

프로젝트 루트에서 스크립트를 실행한다:

```bash
bash .agents/skills/health-check/scripts/health-check.sh
```

스크립트는 SSH를 통해 프로덕션 서버에 접속하여 아래 항목을 순차 검증하고 PASS/FAIL/WARN 리포트를 출력한다.

### 수동 확인 (1개 항목)

하단 여백(iframe 높이)은 브라우저 렌더링이 필요하므로 자동화 대상에서 제외한다. 스크립트 종료 시 수동 확인 URL을 안내한다.

---

## 📋 검증 항목

| # | 항목 | 검증 방법 | 판정 기준 |
|---|---|---|---|
| 1 | **홈페이지 메인** | `curl` HTTP 상태 + 응답 크기 | 200 AND > 10KB → PASS |
| 2 | **출석체크 (비인증 차단)** | `curl` 쿠키 없이 접근 | 403 → PASS |
| 3 | **출석체크 (인증 접근)** | DB에서 유효 세션키 조회 후 쿠키로 접근 | 200 → PASS |
| 4 | **SSL 인증서** | `openssl s_client` 만료일 조회 | ≥ 14일 PASS, 7-13일 WARN, < 7일 FAIL |
| 5 | **디스크 + 컨테이너** | `df` 사용률 + `docker ps` 컨테이너 수 | 디스크 < 80% AND 컨테이너 ≥ 3 → PASS |
| 🔧 | **하단 여백** | (수동) 브라우저에서 육안 확인 | 스크립트가 URL 출력 |

---

## ⚠️ 전제 조건

- SSH 키 인증이 설정되어 있어야 한다 (`ssh -p 2222 wonhyukc@45.115.154.229`)
- mountain 머신 IP에서만 접속 가능 (방화벽 제약)
- 이 스킬은 **READ-ONLY** 작업만 수행한다 (서버 변경 없음)
