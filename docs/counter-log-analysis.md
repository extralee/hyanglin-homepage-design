## 5. 분석 방법론

- **UV 기준**: 날짜+IP 중복 제거 (같은 날 같은 IP = 1회)
- **Bot 분리**: UA 키워드 기반 (`bot`, `spider`, `crawler` 등) — 별도 파일 저장
- **한국 인앱**: 네이버 인앱, 카카오톡 별도 분류
- **분석 스크립트**: `tmp/counter-log-analysis/analyze.py`, `analyze_extra.py`
