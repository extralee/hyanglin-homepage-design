# 서버 접속을 위한 인증 가이드 (SSH/SFTP)

이 문서는 서버에 안전하게 접속하기 위한 `.pem` 키 파일 생성 및 사용법, 그리고 필요에 따라 패스워드 접속을 허용하는 방법을 안내합니다.

---

## 1. 새로운 `.pem` 파일(인증 키) 생성 및 등록

단순히 파일질라나 터미널에서 비밀번호로 접속하는 대신, 높은 보안 수준을 위해 `.pem` 키 파일을 생성하여 접속하는 것이 좋습니다.

### 1.1 키 쌍(Public/Private Key) 생성
로컬 PC의 터미널을 열고 `ssh-keygen` 명령어를 사용하여 새로운 자물쇠(공개키)와 열쇠(개인키, `.pem`) 쌍을 만듭니다.

```bash
# RSA 방식의 4096비트 보안 수준으로 새 pem 파일 생성
ssh-keygen -t rsa -b 4096 -m PEM -f $HOME/.ssh/hyanglin_key.pem
```
*명령어를 입력하면 비밀번호(passphrase)를 추가로 설정할지 묻습니다. 그냥 엔터(`Enter`)를 두 번 치시면 비밀번호 없이 파일만으로 접속 가능한 키가 생성됩니다.*

위 명령어를 실행하면 두 개의 파일이 생깁니다:
1. `hyanglin_key.pem` (나만 가지고 있어야 하는 프라이빗 키 / 파일질라에 넣을 파일)
2. `hyanglin_key.pem.pub` (서버에 등록해야 하는 공개키)

### 1.2 서버에 자물쇠(공개키) 등록 [중요]
단순히 내 PC에서 `.pem` 파일을 만들었다고 해서 곧바로 서버에 접속할 수 있는 것은 아닙니다. 생성된 **공개키(자물쇠)**를 서버에 먼저 등록해 주어야 합니다.

1. `hyanglin_key.pem.pub` 파일의 텍스트 내용을 복사합니다.
2. 접속하려는 서버 내부의 `/root/.ssh/authorized_keys` 파일 안에 해당 텍스트를 한 줄 추가합니다.

> **참고:** 현재 패스워드 접속이 막혀서 서버에 아예 들어갈 수 없는 상태라면, 기존에 권한이 있는 사용자에게 공개키를 전달하여 등록을 부탁하거나, 호스팅 웹 콘솔을 통해 접속해야 합니다.

## 2. `.pem` 파일을 이용한 접속 방법

### 2.1 터미널(SSH)에서 접속하기
```bash
ssh -i $HOME/.ssh/hyanglin_key.pem -p 2222 root@45.115.154.229
```

### 2.2 파일질라(FileZilla)에서 접속하기
1. 우측 중간에 있는 **로그온 유형(Logon Type)**의 드롭다운 메뉴를 클릭합니다.
2. 현재 `일반`으로 되어 있는 것을 **`키 파일 (Key file)`**로 변경합니다.
3. 그러면 아래쪽의 '비밀번호' 입력 칸이 사라지고, **키 파일 경로를 찾아볼 수 있는 버튼(찾아보기...)**이 나타납니다.
4. 해당 버튼을 클릭한 뒤, PC에 저장되어 있는 **`.pem` 파일(서버 프라이빗 키)**을 선택해 줍니다. 
   *(파일질라 버전/OS에 따라 `.pem` 파일을 선택하면 파일질라 전용 형식인 `.ppk`로 자동 변환할 것인지 묻는 창이 나올 수 있는데, 이때 '예'를 누르고 저장하시면 됩니다.)*
5. 하단의 **[연결]** 버튼을 누르시면 키 파일을 이용해 서버에 정상적으로 접속될 것입니다.

## 3. [별첨] 암호(Password) 접속을 허용하도록 설정하기

보안상 `.pem` 파일 사용을 권장하지만, 부득이하게 비밀번호만으로 접속해야 한다면 서버 내부의 SSH 설정 파일(`sshd_config`)을 수정해야 합니다. 
*(이 작업은 이미 서버에 접속 권한이 있는 상태에서만 수행 가능합니다.)*

### 3.1 SSH 설정 파일 열기
터미널에서 아래 명령어를 입력하여 설정 파일을 엽니다. (텍스트 에디터인 `nano` 또는 `vi`를 사용합니다.)
```bash
sudo nano /etc/ssh/sshd_config
```

### 3.2 패스워드 인증 켜기
파일 내용 중 `PasswordAuthentication` 항목을 찾아 `no`로 되어 있는 것을 **`yes`**로 변경합니다. (앞에 `#`이 있다면 지워서 주석을 해제합니다.)
```text
PasswordAuthentication yes
```

### 3.3 root 계정 패스워드 로그인 허용하기 (선택사항)
`root` 계정으로 바로 접속해야 한다면 아래 항목도 찾아서 변경합니다. (`prohibit-password`나 `no`로 되어 있는 것을 `yes`로 바꿉니다.)
```text
PermitRootLogin yes
```
*(주의: root 계정의 패스워드 오픈은 해킹의 주 표적이 되므로 권장하지 않으며, 작업 완료 후 다시 막아두는 것이 좋습니다.)*

### 3.4 변경사항 저장 및 서비스 재시작
`nano` 에디터를 사용했다면 `Ctrl+O` -> `Enter` -> `Ctrl+X` 순서로 저장 후 종료합니다.
이후 설정 적용을 위해 SSH 서비스를 재시작합니다.

```bash
# Ubuntu, Debian 계열
sudo systemctl restart ssh

# CentOS, RedHat, Amazon Linux 계열
sudo systemctl restart sshd
```

이제 파일질라나 터미널에서 `.pem` 키 파일 없이도 설정된 비밀번호만으로 접속이 가능합니다.
