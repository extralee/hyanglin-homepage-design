# Task 001: 데이터 자산화(보석화)를 위한 AI 워크플로 및 스킬 제안서

과거 17,000여 건의 레거시 게시판 데이터를 단순한 텍스트 뭉치가 아닌 **LLM 및 Knowledge Base 용 고품질 데이터(보석)로 정제**하기 위해, AI 에이전트가 준수하고 활용해야 할 워크플로와 스킬들을 제안합니다.

---

## 1. 주요 워크플로 (Workflows) 제안

새롭게 정의하여 `.agents/workflows/` 에 등록하면 좋을 맞춤형 워크플로입니다.

### 🔄 `/task001-etl-pipeline` (데이터 추출 파이프라인 워크플로)
데이터를 한 번에 뽑는 것이 아니라 안정적인 **ETL(Extract, Transform, Load)** 파이프라인으로 설계합니다.
- **Extract**: 로컬 MySQL 컨테이너에서 글 본문과 '댓글' 데이터를 JOIN하여 500건씩 청크(Chunk) 단위로 추출.
- **Transform**: HTML-to-MD 변환 ➡️ YAML Frontmatter 생성 ➡️ 민감정보 마스킹 ➡️ 댓글 병합.
- **Load**: `data/free01/YYYY/MM/ID.md` 형태의 분산 디렉토리에 파일 쓰기.

### 🛡️ `/task001-sanitization` (데이터 정제 및 마스킹 워크플로)
LLM이 맥락을 이해하는 데 필요한 정보와 버려야 할 정보를 명확히 구분하는 규칙입니다.
- **유지 (Keep)**: 작성자 실명, 본문 텍스트, 의미 있는 첨부 이미지 링크.
- **마스킹 (Mask)**: 이메일(`@` 포함 정규식), 전화번호(`010-xxxx-xxxx` 등).
- **제거 (Remove)**: 깨진 이미지 엑스박스, 웹 에디터 폰트 색상 태그(`<span style="...">`), 악성 스크립트.

---

## 2. AI를 위한 핵심 규칙 (AI Core Rules)

에이전트가 스크립트를 짜거나 실행할 때 반드시 명심해야 할 규칙입니다. (`1prd.md` 하위 룰로 추가 권장)

1. **메모리 보호 (No Out-Of-Memory)**
   - 17,000건의 데이터를 한 번에 메모리에 적재하거나 변수에 담지 않습니다. 반드시 **스트리밍(Streaming) 또는 페이지네이션(Pagination)** 기반으로 스크립트를 작성하여 OS와 에디터의 다운을 방지합니다.
2. **멱등성 보장 (Idempotent Execution)**
   - 대규모 추출 중 에러가 발생해 스크립트가 멈추더라도, 재실행 시 **처음부터 다시 중복 생성하지 않고** 실패한 지점부터 이어가거나(Resume), 기존 파일을 덮어쓰도록 안전하게 설계해야 합니다.
3. **스키마 기반 메타데이터 (Strict Frontmatter)**
   - YAML 메타데이터의 Key(작성일, 카테고리, 태그 등)는 사전에 정의된 엄격한 스키마를 따릅니다. 이는 추후 Vector DB나 RAG(검색 증강 생성) 시스템 구축 시 필터링 속도와 정확도를 결정짓는 핵심 요소가 됩니다.

## 3. 필수 커스텀 스킬 (AI Skills 제안)

글로벌 워크플로 `/ai-add-skill`을 통해 `.agents/skills/` 폴더에 등록하여 에이전트가 언제든 호출할 수 있게 만들면 좋은 도구들입니다.

### 🛠️ `skill-mysql-fetcher` (안전한 DB 조회기)
- **기능**: `.env.local`의 `LEGACY_DB_URL`을 활용해 안전하게 Read-only로 데이터를 조회.
- **특징**: 복잡한 레거시 테이블 구조(예: XE 게시판의 `xe_documents`와 `xe_comments` 테이블 조인)를 미리 쿼리로 래핑해둔 유틸리티 스킬.

### 🛠️ `skill-html2md` (레거시 HTML 파서)
- **기능**: 과거 게시판 특유의 지저분한 HTML 태그를 깔끔한 Markdown으로 변환.
- **특징**: `turndown` 같은 라이브러리를 활용하되, 커스텀 룰을 추가하여 의미 없는 `<div>`, `<br>` 남발을 정제하는 특화 스킬.

### 🛠️ `skill-pii-masker` (개인정보 정제기)
- **기능**: 텍스트 내의 민감 정보를 정규표현식(Regex)으로 탐지하여 `***`로 치환.
- **특징**: '실명은 보존한다'는 정책에 따라, 일반적인 3글자 단어는 건드리지 않고 명확한 패턴(이메일, 폰번호)만 필터링하는 정교한 정규식 스킬.
