# 향린교회 홈페이지 신규 디자인 분석 및 사양서 (`new-design.md`)

본 문서는 `docs/홈페이지-디자인4.pdf` 파일의 시안 분석을 바탕으로 정리된 향린교회 신규 홈페이지 디자인 및 기능 개편 사양서입니다.

---

## 1. 개요 및 디자인 컨셉

- **메인 테마**: "We Go Where Jesus Is - 작은 믿음 다시 모아 새로 심는 향린 70"
- **반응형 지원**: PC 및 모바일(Mobile) 레이아웃 전면 지원 (모바일은 상단 햄버거 메뉴 제공)
- **비주얼 구성**: 
  - 상단 메인 비주얼 영역 (랜덤/순차 슬라이드 이미지 + 매주 주일예배 안내 오버레이 카드)
  - 하단 원형 버블 퀵메뉴 (주요 메뉴 바로가기 및 레이어 팝업 연동)

---

## 2. 메인 페이지 레이아웃 및 관리 시스템

### 2.1 메인 비주얼 슬라이드
- **이미지 출처**: `[관리 게시판1]` (별도 생성 예정)에 등록된 최근 이미지 5장 사용
- **동작 방식**: 
  - 홈페이지 최초 접속 시 5장 중 **랜덤**으로 시작
  - 좌측 방향으로 **순차 이동 (슬라이드)**

### 2.2 주일예배 안내 오버레이 카드
- **텍스트 출처**: `[관리 게시판2]`에 매주 등록 (날짜, 설교 제목, 성서 본문, 설교자 등)
- **[주일예배 ▶] 버튼**: 
  - 클릭 시 새 창에서 유튜브 예배 영상으로 이동
  - 해당 유튜브 링크 역시 `[관리 게시판2]`에서 매주 등록 및 관리

## 3. 하단 원형 버블 퀵메뉴 & 팝업 UI (4가지 유형)

하단 비주얼 영역의 버블 메뉴(`하늘뜻펴기`, `기도`, `성서묵상`, `예배안내`, `주보`, `교회소개`, `목회자`, `뜻나눔`, `교육`, `프로그램`, `알림과 소통`, `Why?`)는 GNB 메뉴와 직접 매핑되거나 4가지 형태의 팝업 오버레이를 호출합니다.

### 팝업 메뉴 유형 분석
1. **팝업 유형 1 (설교/동영상 목록)**:
   - 예: `하늘뜻펴기` 클릭 시
   - 설교 날짜, 제목, 설교자 정보와 함께 `[설교문]` 및 `▶(유튜브 영상)` 버튼 제공
   - `▶` 클릭 시 새 창으로 유튜브 동영상 재생 / `[설교문]` 클릭 시 게시물 상세로 이동
   - 하단 `[전체목록 ▶]` 버튼 제공
2. **팝업 유형 2 (기도문/텍스트 목록)**:
   - 예: `기도` 클릭 시
   - 감사기도, 목회기도 등 최근 게시글 목록 및 `[전체목록 ▶]` 링크 제공
3. **팝업 유형 3 (프로그램/행사 카드 뉴스 갤러리)**:
   - 예: `프로그램`, `알림과 소통` 클릭 시
   - 사회개혁, 수요평화거리기도회, 강좌 포스터 등을 가로 스크롤/카드시트 형태로 시각화
4. **팝업 유형 4 (최근 게시글 리스트)**:
   - 최근 공지 및 활동 게시글의 리스트 뷰 및 작성자/댓글 수 정보 제공

## 5. 개발 및 이전 시 핵심 고려사항

1. **메인 이미지 및 설교 관리 게시판 분리**:
   - `[관리 게시판1]`: 슬라이드 이미지 5장 무작위 순차 로딩 기능 구현
   - `[관리 게시판2]`: 주일예배 관련 텍스트 및 유튜브 링크 연동 기능 구현
2. **아카이브 연동 항목**:
   - `교회 연혁` (사건 중심 / 인물 중심 탭 구분)
   - `교인돌봄시스템`, `옛홈페이지`, `향린아카이브`
3. **권한 제어**:
   - 교인전용게시판, 주일출석명부, 교인돌봄시스템, 관리자 메뉴 등 권한 사용자 전용 페이지 로그인/인가 처리
