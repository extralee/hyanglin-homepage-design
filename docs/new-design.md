# 향린교회 웹사이트 현대적 UX/UI 개편 제안서 (`new-design.md`)

---

## 📋 개요

본 문서는 `docs/홈페이지-디자인4.pdf` 시안에 대한 객관적인 디자인/UX 비평(Critique)과, 이를 바탕으로 2026년 기준 현대 웹 트렌드 및 향린교회 공동체의 정체성에 맞춘 **새로운 현대적 웹사이트 개편 제안**을 담고 있습니다.

---

## Part 1. 레거시 시안 (`홈페이지-디자인4.pdf`) 비평 및 한계점

기존 시안은 과거 2000년대 중반 Flash 웹사이트 및 초기 XE/제로보드 시절의 UX 패러다임에 머물러 있어, 현대 사용자 경험(UX) 및 모바일 환경에 몇 가지 치명적인 문제점을 지니고 있습니다.

### 1.1 팝업 모달(Modal Overlay) 남발로 인한 UX 단절
- **문제점**: 하단 버블 메뉴 클릭 시 화면 중앙에 모달 팝업이 뜨며 설교 목록, 기도문, 행사 포스터를 보여주는 방식입니다.
- **영향**:
  - **사용자 흐름 단절**: 팝업창은 사용자의 탐색 흐름을 계속 방해하며 '닫기(X)'를 강제합니다.
  - **모바일 경험 악화**: 모바일 기기에서 팝업창은 화면을 과도하게 가리고, 뒤로가기(Back) 버튼 작동 시 팝업이 닫히는 대신 이전 페이지로 이탈하는 심각한 모바일 UX 오류를 유발합니다.
  - **SEO 및 검색 노출 불리**: 주요 정보(설교, 기도, 소식)가 모달 레이어 뒤에 숨겨져 있어 구글/네이버 등의 검색 엔진이 콘텐츠를 올바르게 인덱싱하기 어렵습니다.

### 1.2 비정형 원형 버블(Bubble) 메뉴의 시각적 혼란
- **문제점**: 화면 하단에 12개의 원형 버블이 떠 있는 구조입니다.
- **영향**:
  - **시각적 위계(Visual Hierarchy) 부재**: 중요도(예: 주일예배, 설교 vs 단순 자료실) 구분 없이 모든 메뉴가 동일한 원형 버블로 산만하게 배치되어 시선 유도가 어렵습니다.
  - **터치 영역 및 가독성 문제**: 모바일 화면에서 작은 원형 타겟은 오타 클릭을 유발하며 텍스트 가독성이 떨어집니다.

### 1.3 파편화된 수동 게시판 관리 방식
- **문제점**: 메인 이미지 슬라이드용 `[관리 게시판1]`, 주일예배 안내용 `[관리 게시판2]` 등 메인 요소마다 개별 게시판을 생성하고 매주 수동 관리하는 구조입니다.
- **영향**: 게시판 운영자의 업무 피로도가 가중되며, 데이터 연동(예: 유튜브 API 자동 연동 등)이 되지 않아 관리가 비효율적입니다.

## Part 2. 현대적 웹 UX/UI 제안 (Modern Redesign Concept)

새로운 향린교회 웹사이트는 **"모던 스토리텔링 랜딩 페이지"**와 **"벤토 박스(Bento Box) 그리드 레이아웃"**을 도입하여, 팝업 없이 스크롤만으로 교회의 모든 최신 소식과 깊이 있는 메시지를 자연스럽게 접할 수 있도록 설계합니다.

```
+-------------------------------------------------------------------+
|                         Sticky Header                             |
|  [Logo: 향린교회]     교회소개   목회마당   게시와활동   아카이브    [검색/메뉴] |
+-------------------------------------------------------------------+
|                                                                   |
| [HERO SECTION]                                                    |
| - 고화질 묵상 슬라이드 / 비디오 배경                                 |
| - 이번 주 하늘뜻 (설교) 요약 & "온라인 예배 참여" CTA 버튼            |
|                                                                   |
+-------------------------------------------------------------------+
| [BENTO GRID SECTION - 주요 콘텐츠 카드]                           |
| +-------------------------+ +-----------------------------------+ |
| | 🎥 최신 하늘뜻 (설교)   | | 📢 향린 소식 & 알림             | |
| | - 설교 비디오/오디오    | | - 카드 뉴스 갤러리 슬라이더     | |
| +-------------------------+ +-----------------------------------+ |
| +-------------------+ +-------------------+ +-------------------+ |
| | 🙏 오늘의 기도    | | 📖 이번주 성서읽기| | 🕊️ 향린 70주년    | |
| | - 성서 묵상      | | - 주보 다운로드   | | - 아카이브 타임라인| |
| +-------------------+ +-------------------+ +-------------------+ |
+-------------------------------------------------------------------+
| [INTERACTIVE ARCHIVE & COMMUNITY]                                 |
| - 사건/인물 중심 향린 역사 타임라인                                |
+-------------------------------------------------------------------+
| [FOOTER]                                                          |
| - 오시는 길, 예배 시간, 헌금 계좌, SNS 연동                       |
+-------------------------------------------------------------------+
```

### 2.1 핵심 UX/UI 개선 전략

1. **팝업 제로(Zero-Popup) & 스크롤 기반 스토리텔링**
   - 모든 팝업을 제거하고, 메인 화면을 스크롤하며 직관적으로 콘텐츠를 소비할 수 있는 랜딩 페이지 구조로 변경합니다.
   - 상세 내용이 필요한 경우 전용 페이지로 깔끔하게 전환되거나, 아코디언/인라인 인스턴트 드로어로 처리합니다.

2. **Bento Box 그리드 레이아웃 적용**
   - 애플(Apple), 미디엄(Medium) 등 현대 대표 웹 디자인에서 검증된 Bento Grid 방식을 채택합니다.
   - 콘텐츠의 중요도에 따라 카드 크기를 다르게 배정하여 시각적 몰입감을 극대화합니다.
     - **Big Card**: 최신 주일 설교(영상 플레이어 내장) 및 주요 행사 카드 뉴스
     - **Medium Card**: 이번 주 주보, 공지사항, 기도문
     - **Small Card**: 모임 소식, 성서 읽기, 헌금 안내

3. **스마트 자동화 헤더 & 반응형 메가메뉴 (Megamenu)**
   - **PC**: 상단 고정 헤더에 마우스를 올리면 전체 메뉴 구조가 한눈에 펼쳐지는 메가메뉴 적용.
   - **Mobile**: 하단 고정 빠른 실행 바(Bottom Navigation Bar) 또는 부드러운 슬라이드아웃 Drawer 메뉴 제공.

4. **유튜브 & 미디어 자동 연동 시스템**
   - 수동 게시판 관리 대신 **유튜브 API 연동**을 통해 주일예배 및 설교 영상이 실시간으로 메인 화면에 자동 반영되도록 시스템화합니다.

5. **향린 70주년 인터랙티브 아카이브 (Interactive Archive)**
   - 70년 민주화와 민중신학의 역사를 가진 향린교회의 정체성을 살려, 메인 페이지 하단에 **인터랙티브 타임라인(Timeline)**을 구성합니다.
   - 사건 중심 / 인물 중심으로 연혁과 역사 자료를 시각적으로 둘러볼 수 있게 합니다.

## Part 3. 정보 아키텍처(IA) 및 메뉴 재정비

기존 복잡했던 4대 메뉴 체계를 사용자 중심의 5대 메인 카테고리로 명확히 다듬었습니다.

| 1차 메뉴 | 2차 주요 메뉴 (현대적 재구성) | 특징 및 개선점 |
| :--- | :--- | :--- |
| **교회소개** | 향린의 고백, 목회자/직원, 오시는 길 | 직관적인 인포그래픽 및 찾아오는 길 카카오/네이버 지도 API 연동 |
| **하늘뜻(목회)** | 하늘뜻펴기(설교), 성서묵상, 주보, 기도문 | 미디어 오디오/비디오 플레이어 내장 카드형 뷰 제공 |
| **공동체 & 활동** | 공지사항, 모임과 활동, 언론 속 향린, 자유게시판 | 카드 뉴스 갤러리 및 모던한 커뮤니티 게시판 UI |
| **향린 아카이브** | 70년 역사 타임라인, 신앙고백문서, 사진/영상/음원 | 사건/인물별 아카이브 검색 및 시각화 타임라인 제공 |
| **교인마당 (인증)** | 교인전용게시판, 주일출석, 교인돌봄 | 교인 전용 간편 인증 및 개인화 모바일 대시보드 |

## 🎯 결론 및 향후 개발 방향

레거시 디자인(`홈페이지-디자인4.pdf`)의 산만했던 팝업 기반 버블 구조를 과감히 벗어나, **"명확한 시각적 계층 구조, 팝업 없는 모바일 친화적 롱스크롤, 미디어 자동 연동"**을 골자로 하는 현대적 디자인을 제안합니다.

이 방안은 향린교회의 70년 신학적 역사성을 현대적 미학으로 계승하면서도, 교인과 신규 방문자 모두에게 쾌적하고 세련된 웹 경험을 제공할 것입니다.
