# 향린교회 레거시 서버 마이그레이션 테스트 시나리오

DNS(도메인)를 신규 서버로 완전히 전환하기 전에, 사용자님 PC에서 먼저 신규 서버(가비아)로 접속하여 모든 기능이 정상 작동하는지 검증할 수 있습니다. 

## 1. 테스트 환경 설정 방법 (`hosts` 파일 변조)

사용자님의 PC에서 도메인(`hyanglin.org`) 접속 시 임시로 구 서버가 아닌 신규 가비아 서버(`45.115.154.229`)로 연결되도록 설정합니다.

### Windows의 경우
1. **메모장**을 **관리자 권한**으로 실행합니다.
2. `C:\Windows\System32\drivers\etc\hosts` 파일을 엽니다.
3. 파일 맨 아래에 다음 두 줄을 추가하고 저장합니다.
   ```text
   45.115.154.229 hyanglin.org
   45.115.154.229 www.hyanglin.org
   ```
4. 브라우저를 열고 `http://www.hyanglin.org` 에 접속합니다.

### Mac/Linux의 경우
1. 터미널을 열고 `sudo nano /etc/hosts` 명령어를 입력합니다.
2. 맨 아래에 위와 동일하게 IP와 도메인을 추가하고 저장합니다.

> [!TIP]
> 테스트가 완전히 끝나고 실제 DNS를 변경할 때는 위에서 추가한 줄을 다시 지워주셔야 합니다.

## 2. 사용자 직접 검증(UAT) 시나리오

브라우저 캐시를 비우거나 시크릿 모드(Incognito)를 열고 다음 시나리오를 테스트해 보세요.

### ✅ 시나리오 1: 메인 페이지 및 외부 종속성(IFRAME) 렌더링
- **테스트 방법**: 브라우저에서 메인 페이지(`http://www.hyanglin.org`) 접속
- **확인 사항**:
  - 화면 정중앙의 '피아노 슬라이더' 위젯이 정상적으로 이미지를 넘기며 표시되는가?
  - 중앙부 하단의 12개 아이콘 메뉴와 '오늘의 말씀' 텍스트가 정상 출력되는가?
  - (이 부분들이 안 보인다면 앞서 발생했던 500 에러나 `contents` 누락 문제가 재발한 것입니다.)

### ✅ 시나리오 2: 게시물 읽기 및 첨부파일(이미지) 확인
- **테스트 방법**: '목회/설교'나 '자유게시판' 등 사진이 포함된 기존 게시물 하나를 클릭하여 열람
- **확인 사항**:
  - 게시물 본문의 텍스트가 깨지지 않고 잘 보이는가? (인코딩 확인)
  - 본문에 첨부된 사진 이미지들이 엑스박스(X) 없이 정상적으로 로드되는가? (`files/` 디렉터리 권한 및 동기화 점검)

### ✅ 시나리오 3: 로그인 및 세션 유지
- **테스트 방법**: 우측 상단이나 메뉴의 로그인 버튼을 눌러 기존 관리자 또는 회원 계정으로 로그인
- **확인 사항**:
  - 로그인 후 메인 페이지로 돌아왔을 때 로그인 상태가 유지되는가?
  - 관리자 페이지 톱니바퀴(`설정`) 메뉴 접속 시 정상 진입되는가?

### ✅ 시나리오 4: 글쓰기 및 파일 업로드 (DB Write 테스트)
- **테스트 방법**: '자유게시판' 등 권한이 있는 게시판에 `[테스트]`라는 제목으로 새 글 작성 및 사진 파일 첨부 후 등록
- **확인 사항**:
  - 에러 없이 글이 등록되는가? (DB Write 권한 및 용량 확인)
  - 등록된 글의 첨부파일(사진)이 제대로 출력되는가?
  - 테스트 완료 후 해당 글을 정상적으로 삭제할 수 있는가?

## 3. 자동화 테스트 스크립트 (CLI)

브라우저 테스트 외에, 터미널에서 신규 서버의 상태 코드를 즉시 검사해보고 싶으시다면 아래의 `curl` 명령어를 복사하여 실행해 보세요. 모두 `HTTP/1.1 200 OK`가 나와야 정상입니다.

```bash
# 1. 메인 페이지 정상 응답 확인
curl -sI -H "Host: www.hyanglin.org" http://45.115.154.229/

# 2. IFRAME 컴포넌트(이전 500 에러 발생 지점) 정상 응답 확인
curl -sI -H "Host: www.hyanglin.org" http://45.115.154.229/contents/main.php
```
